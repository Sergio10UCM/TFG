# **Trabajo de Fin de Grado (TFG)**

Este repositorio contiene el código fuente desarrollado para mi Trabajo de Fin de Grado. El proyecto se centra en la importación, exploración y validación de hipótesis mediante técnicas de estadística y Machine Learning.


## 📂 Estructura del Proyecto
El repositorio se divide en dos carpetas principales que contienen los mismos scripts, pero con configuraciones de rutas distintas:

•	*Local Sergio/*: Contiene el código con las rutas absolutas y configuraciones específicas de mi entorno local. Útil para consulta rápida de cómo se ejecutó originalmente.

•	*Reproducible/*: Carpeta optimizada para su ejecución en otros equipos. Los scripts incluyen comentarios indicando dónde se deben introducir las rutas locales para que el código funcione correctamente. Además, el código en esta carpeta cuenta con comentarios más detallados.

## 🛠 Contenido de las Carpetas

Ambos directorios siguen el mismo flujo de trabajo:

	1.	*Importacion.R*: Script encargado de la carga de datos crudos y la limpieza inicial.
    
	2.	*Exploracion.R*: Análisis exploratorio de datos (EDA), visualizaciones y estadísticas descriptivas.
    
	3.	Contraste de Hipótesis: Dividido por lenguajes para aprovechar las potencias de cada ecosistema:
    
            •	*Hipotesis1.R*: Modelado estadístico y pruebas realizadas en R.
            
            •	*Hipotesis2.py*: Implementación de modelos de Machine Learning y análisis avanzado en Python.

## 🚀 Instrucciones de Uso (Modo Reproducible)

Para ejecutar el proyecto en un nuevo entorno, sigue estos pasos:

	1.	Accede a la carpeta Reproducible/.
    
	2.	Abre los archivos .R o .py según corresponda.
    
	3.	Busca la sección "Configuración de rutas" al inicio de cada script y sustituye las direcciones por las de tu directorio local donde se encuentren los datasets.
    
	4.	Asegúrate de tener instaladas las librerías necesarias especificadas en las cabeceras de los archivos.
